\# E-Commerce Watch Shopping Cart & Inventory System

A robust C++ console application implementing core data structures and algorithms to manage an online watch store's catalog, shopping cart navigation, checkout queue, and administrative logs.

\## Features & Data Structures Implemented

This project showcases advanced data structures and algorithm design principles:

1\. \*\*Binary Search Tree (BST)\*\*: Used for fast product ID lookups and inventory indexing.
2\. \*\*Doubly Linked List (\`ShoppingCart\`)\*\*: Powers the shopping cart, allowing seamless bi-directional navigation (\`next\`/\`prev\`) through selected items.
3\. \*\*Circular Linked List (\`BrandShowcase\`)\*\*: Manages partner brand banners, looping infinitely through featured watch brands.
4\. \*\*FIFO Queue (\`CheckoutQueue\`)\*\*: Handles customer checkout orders sequentially on a first-come, first-served basis.
5\. \*\*LIFO Stack (\`AdminUndo\`)\*\*: Keeps track of administrator actions (add, restock, remove) to allow instant undo capabilities.
6\. \*\*Binary Search Algorithms\*\*: Implemented custom lower-bound and upper-bound search logic for efficient price-range filtering on sorted inventory lists.
